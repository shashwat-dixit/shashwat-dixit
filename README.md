### About

I'm an SDE-1 at [Interview Kickstart](https://interviewkickstart.com) working on payments — gateway integrations, installment billing, and the flow that grants learners access after they pay. Previously at [Instahyre](https://instahyre.com) I built distributed systems, search infrastructure, and cut API latency by 80% (p75: 600ms → 120ms).

Based in Bengaluru. I like working across the stack — from Redis locking to Elasticsearch query parsers to Next.js SPAs.
